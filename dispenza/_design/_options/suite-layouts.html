Our suite — layout options

Four ways to build this section

Every option below is built from the real tokens, type ladder and structural sheet, so what you are comparing is the layout and nothing else. The section currently shows two of eight services — so each option is judged twice: how it reads now, and how it reads when all eight are in it, which is where this is heading.

Option A

Alternating split — what is built today

measured: 1,915px for 2 → ~7,660px for 8

Each service gets a full-width row, text and media swapping sides. The most generous and the most editorial — every service reads like its own page. The cost is height: measured at 1440 it runs 1,915px for two services, so eight would come to roughly 7,700px — about eight screens of scrolling. Best if the suite stays a teaser of two or three with a link to the full page.

Option B

Two-up cards

measured: 697px for 2 → ~1,394px for 8

Media on top, copy beneath, two across. Measured 697px against A’s 1,915px for the same two services — roughly a third of the height — and it keeps the feature lists, which are the part that actually sells. It scales to eight as a plain 2×4 grid with no new rules. The trade is that the media gets small, so it has to carry meaning at a glance — the gauge does, a photograph mostly does not.

Option C

Index rows — all eight, one screen

measured: 649px — already all 8

The whole suite as a numbered index. This is the only option where "eight services" is itself the message — the reader sees the full range in one glance instead of being told there are six more elsewhere. It drops the media and the feature lists, so it trades persuasion for scope; it works best if each row links to a service page that does the selling. Note the eyebrow can then read eight of eight.

Option D

One featured, seven listed

measured: 684px — already 1 + 7

One service gets the full split treatment — media, lede, feature list — and the other seven sit beneath it as chips. Keeps a single strong visual moment without paying for it eight times, and still shows the full range. The open question is which service earns the feature slot, and whether that changes per page or stays fixed.
